# HGSS Stage 4E independent triangle assets

## Finding

The bounded HeartGold map-model transformer can render independent triangles
and quads in one existing shape display list. The project-owned OBJ importer
now accepts explicit three- or four-corner `v/vt/vn` faces under asset manifest
schema 4, keeps their authored order, validates their winding against supplied
normals, and emits consecutive primitive runs deterministically.

Confidence is **high for independent triangles and quads in the exact command,
template-shape, material, texture, coordinate, and US-ROM subset tested by
source inspection, byte parsing, a clean ROM build, live collision, and two
visually inspected runtime views**. This does not establish triangle strips,
fans, N-gons, automatic triangulation, arbitrary materials, or arbitrary model
capacity.

## Source and command evidence

The local `pret/pokeheartgold` evidence tree is revision
`008257708bd41df5b8c9037e019088ba24df0a87`. Its NitroSDK-compatible
`lib/include/nitro/gx/g3.h` declares:

| `GXBegin` value | Meaning | Stage 4E support |
|---:|---|---|
| 0 | independent triangles | yes |
| 1 | independent quads | preserved |
| 2 | triangle strip | rejected |
| 3 | quad strip | rejected |

Apicula revision `3d4e91e14045392a49c89e86dab8cb936225588c`
(0BSD) independently confirms `BEGIN_VTXS` opcode `0x40`, `END_VTXS`
opcode `0x41`, `NORMAL` `0x21`, `TEXCOORD` `0x22`, and `VTX_16` `0x23`.
Its primitive interpreter consumes type 0 in groups of three vertices and type
1 in groups of four. No implementation was copied: the Python encoder and
strict inspector are project-owned.

The bounded emitted form is:

```text
BEGIN(primitive type)
  NORMAL                 once per authored face
  TEXCOORD + VTX_16      once per corner
  ...
END
```

`NORMAL`, `TEXCOORD`, and `VTX_16` encoding is unchanged from the already
runtime-proven quad path. Multiple `BEGIN`/`END` groups are valid. Stage 4E
opens a new group only when the source face type changes, preserving source
order rather than globally regrouping geometry.

## OBJ and neutral IR subset

Accepted faces are exactly:

```text
f v/vt/vn v/vt/vn v/vt/vn
f v/vt/vn v/vt/vn v/vt/vn v/vt/vn
```

Indices must be positive and in range. UVs and normals are mandatory. N-gons,
relative/negative indices, missing components, repeated positions, zero-area
faces, non-planar quads, non-finite values, normal/winding disagreement, UVs
outside the bounded range, fixed-point overflow, and unmapped materials fail
before encoding. Legacy manifest schemas 1--3 remain quad-only so the previous
proof boundary is not silently broadened.

Neutral mesh IR schema 2 records `primitive: triangle|quad` on each face. Face
order is stable and semantic hashes exclude filesystem-dependent metadata.
Cardinal placement rotations transform points and recompute face normals from
the same ordered corners, preserving handedness. Tests cover 0, 90, 180, and
270 degrees and require `cross(edge0, edge1) dot normal > 0` for every face.

## Byte accounting and binary validation

Commands are represented by the existing padded four-byte opcode form. For
the canonical four-face runs:

| Run | Vertices | Content bytes | BEGIN/END bytes | Total bytes |
|---|---:|---:|---:|---:|
| four quads | 16 | 352 | 12 | 364 |
| four triangles | 12 | 272 | 12 | 284 |

Thus one independent triangle costs 68 content bytes and one independent quad
costs 88; each consecutive run adds 12 bytes. Capacity is calculated exactly
before template mutation. The independent inspector rejects unsupported begin
types, nesting, missing or malformed end commands, commands outside a group,
wrong vertex arity, and inconsistent normal/texture-coordinate counts.

The NSBMD model information at `model_base + 36` is updated as four `u16`
values: vertex, polygon, triangle, and quad counts. The Stage 4E generated
model reports 96 vertices, 25 polygons, 4 triangles, and 21 quads including
the flat ground and safety primitives retained in unselected template shapes.

has a four-quad rectangular body and four independent triangular roof facets,
9 source vertices, 5 UVs, and 8 normals. It binds the existing project-owned

| utilization | 60.674% |

show all roof facets, the upright quad body, coherent stone UVs/lighting, and
no neighboring terrain corruption.

## Boundaries

Confirmed by source, binary tests, build, runtime, and visual inspection:

- independent triangle and quad blocks coexist in one map-model shape;
- explicit OBJ triangle UVs/normals survive normalization and cardinal
  placement;
- exact capacity checks prevent model corruption;
- project textures and manifest-derived rectangular collision remain intact.

Confirmed by source and unit tests only:

- all four cardinal rotations preserve winding and normals;
- malformed/corrupt triangle blocks and two-placement overflow fail early;
- triangle-only input is representable by the primitive encoder.

Unknown or deliberately unsupported:

- triangle/quad strips, fans, N-gons, automatic triangulation/topology repair;
- negative OBJ indices, absent normals/UVs, arbitrary transforms/materials;
- display-list relocation, capacity beyond verified shapes, detailed mesh
  collision, GLB/GLTF, simplification, image-to-3D, and production assets.
