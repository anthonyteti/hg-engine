# Stage 2 NSBMD Model Path

Recorded: 2026-08-07

## Finding and recommendation

For the one-map proof, use the project-owned hash-locked NSBMD template transformer in `tools/pokeagent/world.py`. It reads map member 0 from the user's local supported US HeartGold ROM, verifies SHA-256 `f9fbf0196f416739019288f24be604fd6c096a2ec4ebf7e820e116e7ecc329cc`, preserves its model/material/texture dictionaries, replaces every shape display list with deterministic valid geometry, and makes shape 6 a newly encoded flat quad. The resulting model is therefore geometry generated by project code, not an unchanged model recombination.

This is sustainable for the bounded Stage 2 fixture and clears the map-model kill gate. It is not a general NSBMD writer and must not be scaled into production map authoring without a later, separately tested model compiler decision.

## Alternatives investigated

1. Pokemon DS Map Studio revision `ac30b653e5b090ce116278ed6ba9758fff956673` writes IMD, then invokes absent Nintendo `g3dcvtr.exe` with `<imd> -eboth|-emdl -o <output>`. The repository has no license file. This path is proprietary, not redistributable here, and unsuitable for CI.
2. Apicula revision `3d4e91e14045392a49c89e86dab8cb936225588c` is 0BSD and provides strong NSBMD reading/export evidence, but no sufficient NSBMD writer.
3. Every File Explorer revision `f9f00d193c9608d71c9a23d9f3ab7e752f4ada2a` contains a complete writer useful as format corroboration, but no repository license was found. No code was copied or linked.
4. A tiny from-scratch writer is plausible, but the Nitro dictionaries, material/texture bindings, SBC, and model-info invariants make it unjustified for one flat fixture.
5. A user-local `g3dcvtr` prerequisite was rejected because the hash-locked transformer proved sufficient without adding a proprietary converter.

## Legal, reproducibility, and CI implications

- Project code is original implementation informed by inspected formats; it does not redistribute editor code, Nintendo tools, ROM members, or generated models.
- The transformed template remains user-local and is emitted only under ignored `build/` and the ignored generated ROM.
- Reproducibility is byte-for-byte for a fixed canonical fixture, toolchain, and verified source ROM.
- CI needs a lawfully supplied supported ROM just as the existing HG-Engine build does. Public CI cannot publish the ROM, template member, NARCs, screenshots, or playable output.
- Exact API: `generate_world()` calls `transform_template_nsbmd(template_nsbmd, target_shape=6)`; CLI entry is `python -m tools.pokeagent map generate`.

## Reproduction

Run `python -m tools.pokeagent map generate --json`, inspect `build/stage2/generated/components/map_member.bin`, build with `make stage2-proof`, then run the headless map test. The model manifest records template hash, shape count, capacities, selected shape, and encoded display-list length.

## Remaining unknowns

- A production-quality open licensed general NSBMD writer remains unresolved.
- The current proof reuses local commercial material/texture data and cannot publish its generated binary artifacts.
- New materials, textures, node hierarchies, animation, and arbitrary topology are not supported.
